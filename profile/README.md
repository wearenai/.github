# NAI — National AI

AI that answers to Australia.

We're senior software and machine-learning engineers from leading Australian technology companies. We're forming NAI to build Australian-controlled foundation models and AI-native cyber security for government, critical infrastructure and the systems Australians depend on.

NAI is in formation. There is no company or government partnership yet.
